# 사전 리서치 요약 (2026-07-06)

> 하위 리서치 에이전트가 한국어 웹 리서치로 수집. 상세 출처는 하단 참조.

## 핵심 발견

1. **운영 실태**: 세무사 97% 이상 개인사무소 형태. 직원 1인당 평균 약 40개 거래처 담당.
   월 기장료 8만~15만원 수준. 3~5년차 직원 이직이 잦고, 3월·5월 신고 성수기 이탈 시 혼란 극심.
2. **3대 고충** (커뮤니티·기사 공통):
   - 거래처 요청사항을 빠뜨리지 않고 제때 완결하기
   - 신고 기간에 거래처별 신고 준비 진행도 파악하기
   - 거래처별 수임료·조정료 수금 여부 파악하기
3. **인수인계·지식 종속 문제**: 갑작스러운 퇴사 시 업무 공백, 거래처 특이사항 유실,
   개인 경험 의존으로 표준화 부족. 온보딩 교육 자료 표준화 미흡.
4. **경쟁 솔루션 공백 분석**:

   | 영역 | 기존 솔루션 | 공백 여부 |
   |------|------------|----------|
   | 기장/신고 자동화 | 세무사랑, WEHAGO T, 온리원, 세무특공대 | 충족 (본 기획 제외 영역) |
   | 미수금 자동화 | 온리원, 세무특공대 (일부) | 부분 충족 |
   | 직원 협업/체크리스트 | — | **완전 미충족** |
   | 내부 매뉴얼/지식 관리 | — | **완전 미충족** |
   | 업무 프로세스 표준화 | — | **완전 미충족** |
   | 증빙 아카이빙 | — | **완전 미충족** |

5. **지식저장소 니즈**: 세법 예규·판례는 국세법령정보시스템/삼일 등 외부 채널에 존재하나,
   사무실 내부 노하우·거래처별 특수사항·온보딩 자료를 담는 세무사무소 특화 KMS는 부재.

## 기획 반영 사항

- 직원 협업(태스크/칸반) + 지식저장소(KB) + 진행도 대시보드를 v1 핵심 축으로 확정 (시장 공백 3개 직격)
- KB 카테고리에 업무 매뉴얼(온보딩 포함) 명시, 상담이력→지식화 승격 플로우 유지
- 미수금 관리는 "수금 대행"이 아닌 "가시화 + 알림"으로 범위 한정 (기존 솔루션과 차별)
- 신고기한 캘린더는 국세청 세무일정 기준 + 주말·공휴일 순연 규칙 반영
