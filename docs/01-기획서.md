# TaxDesk (택스데스크) — 세무사무소 인하우스 운영 플랫폼 기획서

> 버전 1.0 · 2026-07-06
> 대상: 대한민국 세무사(세무회계사무소) 사무실 운영
> 범위 제외: 세무사랑/위하고 등 기존 세무 프로그램이 처리하는 기장·신고서 작성·급여·4대보험 업무

---

## 1. 배경 및 문제 정의

### 1.1 배경

세무사 사무실의 "본업"(기장, 신고서 작성, 급여관리)은 세무사랑(더존), 위하고(WEHAGO) 등
전문 프로그램이 담당한다. 그러나 **사무실 운영 그 자체**는 여전히 엑셀, 수기 장부, 카카오톡,
개인 기억에 의존하는 곳이 대부분이다.

### 1.2 현장의 고충 (Pain Points)

| # | 고충 | 현재 방식 | 결과 |
|---|------|----------|------|
| P1 | 신고 시즌마다 거래처별 진행상황 파악이 어려움 | 엑셀 체크리스트를 매번 새로 작성 | 신고 누락 리스크, 마감 직전 야근 |
| P2 | 거래처 자료 수취 독촉이 수작업 | 직원이 일일이 전화/카톡 | 시간 낭비, 독촉 이력 미기록 |
| P3 | 직원 이직 시 인수인계 부실 | 담당자 머릿속 + 개인 메모 | 거래처 특이사항 유실, 클레임 |
| P4 | 세법 노하우·예규·상담 사례가 개인에 종속 | 개인 북마크, 프린트물 | 같은 질문을 반복해서 조사 |
| P5 | 기장료 미수금 관리 부재 | 통장 대조 후 엑셀 기록 | 미수금 방치, 청구 누락 |
| P6 | 일정·업무·알림이 채널별로 분산 | 카톡+전화+포스트잇+엑셀 | 업무 누락, 이중 확인 비용 |
| P7 | 수임/해지 이력, 상담 이력이 축적되지 않음 | 기록 안 함 | 분쟁 시 근거 부재, 재수임 기회 유실 |

### 1.3 목표

> **"신고 프로그램 밖의 모든 사무실 운영 업무를 하나의 채널에서"**

- 업무·일정·알림·지식을 **단일 플랫폼**으로 통합 (P6)
- 신고 기한 기반 업무를 **자동 생성·자동 알림** (P1, P2)
- 거래처·상담·노하우를 **조직 자산으로 축적** (P3, P4, P7)
- 기장료 청구·미수금의 **가시화** (P5)

### 1.4 비(非)목표 (Out of Scope)

- 기장(전표 입력), 신고서 작성·전자신고, 급여·4대보험 신고 → 세무사랑/위하고 영역
- 홈택스 직접 연동(스크래핑) → 법적·기술적 리스크로 v1 제외, 수임동의 "상태"만 수기 관리
- 거래처(납세자)용 외부 포털 → v2 후보
- 카카오 알림톡 실발송 → v1은 인앱 알림 + 이메일 스텁, 발송 어댑터 인터페이스만 설계

## 2. 사용자 정의 (Personas)

| 역할 | 설명 | 핵심 니즈 |
|------|------|----------|
| **대표세무사 (admin)** | 사무소 대표. 전체 현황 관제 | 전 거래처 진행률, 미수금, 직원별 업무량 한눈에 |
| **팀장/실장 (manager)** | 업무 배분·검토 | 시즌 업무 일괄 생성, 담당자 배정, 지연 업무 파악 |
| **담당 직원 (staff)** | 거래처 20~80곳 담당 | 오늘 할 일, 내 거래처 기한, 자료수취 현황 |

조직 규모 가정: 직원 3~30인 사무소 (국내 세무사무소의 대다수).

## 3. 핵심 기능 (Modules)

### M1. 통합 대시보드 — "하나의 채널"
- 오늘/이번 주 할 일, 다가오는 신고 기한 D-day, 미수금 요약, 자료수취 현황, 최근 알림
- 역할별 뷰: 대표는 사무소 전체, 직원은 본인 담당분

### M2. 거래처(수임처) 관리 — CRM
- 거래처 마스터: 사업자번호, 상호, 대표자, 과세유형(법인/일반/간이/면세), 업종, 연락처
- 수임 정보: 수임일, 기장료(월), 조정료, 담당 직원, 수임동의 상태, 계약 상태(수임중/해지)
- 상담·연락 이력 타임라인 (전화/방문/카톡 기록), 특이사항 메모 → 인수인계 자산
- 해지 프로세스: 해지 사유 기록, 인계 체크리스트

### M3. 세무 캘린더 & 기한 관리
- **신고기한 마스터 내장**: 원천세(매월 10일), 부가세 예정·확정(1/25, 4/25, 7/25, 10/25),
  법인세(3/31), 종합소득세(5/31), 성실신고(6/30), 사업장현황신고(2/10),
  지급명세서(3/10 등), 원천세 반기납부(1/10, 7/10), 면세 수입금액명세(2/10) 등
- 주말·공휴일 순연 규칙 반영
- 사내 일정(회의, 휴가, 교육) 등록, 월/주 캘린더 뷰, 담당자별 필터

### M4. 업무(태스크) 관리
- 태스크: 제목, 거래처, 담당자, 기한, 우선순위, 상태(대기/진행/검토/완료), 체크리스트
- **시즌 일괄 생성**: "부가세 확정신고" 실행 → 부가세 대상 거래처 전체에 태스크 자동 생성
- 칸반 보드 + 리스트 뷰, 지연 업무 하이라이트
- 업무 템플릿: 신고 유형별 표준 체크리스트(자료수취→검토→신고→납부안내) 정의·재사용

### M5. 자동화 엔진
- 규칙: `트리거(신고기한 D-n / 매월 n일 / 상태변화) → 액션(태스크 생성 / 알림 발송)`
- 기본 제공 규칙 예:
  - 원천세: 매월 1일에 전 거래처(원천세 대상) 태스크 생성, D-3 미완료 시 담당자 알림
  - 부가세: 신고월 1일에 자료수취 태스크 생성, D-7 자료 미수취 거래처 목록 알림
  - 기장료: 매월 청구 레코드 자동 생성, 미납 30일 경과 시 알림
- 실행 기록(automation_runs) 저장 → 중복 실행 방지, 감사 가능

### M6. 지식저장소 (Knowledge Base)
- 마크다운 위키: 카테고리(세목별/업무 매뉴얼/사무소 규정/상담 사례), 태그
- 예규·판례·해석례 스크랩: 출처 URL + 요약 + 관련 세목
- 전문검색(한국어 형태소 고려한 Postgres FTS + trigram 폴백)
- 문서 개정 이력(버전) 보관, 작성자 표시
- 상담 이력(M2)에서 "지식화" 버튼 → 상담 사례를 KB 문서로 승격

### M7. 기장료 청구·미수금 관리
- 거래처별 월 기장료 기반 청구 레코드 자동 생성(M5 연동)
- 입금 기록(수기), 미수금 현황판(거래처별/기간별), 조정료 등 비정기 청구
- ※ 세금계산서 발행 자체는 기존 프로그램 사용 (본 시스템은 수금 "관리")

### M8. 문서함
- 거래처별 폴더: 수임계약서, 위임장, 신분증 사본 등 (Supabase Storage)
- 업로드 시 거래처·문서유형 태깅, 만료일 관리(예: 위임장 갱신)

### M9. 알림 센터
- 인앱 알림 피드(단일 채널): 자동화 알림, 배정 알림, 멘션, 기한 임박
- 읽음 처리, 유형별 필터. 이메일 발송은 어댑터 인터페이스로 확장 준비

### M10. 직원·권한 관리
- 역할: admin / manager / staff — RLS로 데이터 접근 제어
- 초대 기반 가입, 담당 거래처 재배정(퇴사·이직 대응), 감사 로그

## 5. 성공 지표 (KPI)

- 신고 시즌 태스크 누락 0건 (완료율 100% 추적 가능)
- 자료수취 독촉 소요 시간 주당 3시간 → 30분
- 신규 직원 인수인계 기간 2주 → 3일 (거래처 이력·KB 활용)
- 미수금 파악 소요: 월 1회 수작업 → 실시간

## 7. 디자인 방향

Google Stitch 스타일의 모던 SaaS 대시보드 언어를 채택하되, Stitch는 API 접근이 불가하므로
동일 계열의 디자인 토큰을 자체 정의한다 (구현설계서 §7 디자인 시스템 참조).
- 좌측 고정 사이드바 + 상단 검색/알림 바 + 카드 기반 콘텐츠
- 한국어 최적화: Pretendard 폰트, 숫자·날짜 표기 ko-KR
- 라이트/다크 모드, 데이터 밀도 높은 테이블 중심 화면
